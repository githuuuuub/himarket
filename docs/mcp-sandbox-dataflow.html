🔥 订阅流程（冷数据 → 热数据转换）
用户点击"订阅"按钮后的决策流程
用户点击「订阅」
⚙️ himarket-server 检查热数据表
✅ 有热数据（网关导入的）
直接创建订阅记录
将热数据(MCP链接)展示在
「我的MCP」中
❌ 无热数据
调用 AgentRun 沙箱服务
传入MCP元数据
↓
AgentRun 返回 MCP endpoint
↓
保存到热数据表
创建订阅记录
展示在 「我的MCP」中
详细时序
用户 → Frontend : 点击「订阅」按钮 Frontend → Server : POST /mcp-market/{id}/subscribe Server → DB : 查询热数据表 WHERE mcp_cold_id = {id} DB → Server : 返回结果 【分支A：有热数据（网关导入）】 Server → DB : 创建订阅记录 (user_id, mcp_cold_id, mcp_hot_id) Server → Frontend : 返回 {mcpEndpoint, status: "ready"} Frontend → 用户 : 展示在「我的MCP」，可直接使用 【分支B：无热数据（需AgentRun托管）】 Server → DB : 查询冷数据表获取MCP元数据 Server → AgentRun : POST 沙箱API {sourceType, sourceUrl, envVars, tools} AgentRun → Server : 返回 {instanceId, mcpEndpoint} Server → DB : 写入热数据表 (mcp_cold_id, endpoint, sandbox_instance_id) Server → DB : 创建订阅记录 (user_id, mcp_cold_id, mcp_hot_id) Server → Frontend : 返回 {mcpEndpoint, status: "ready"} Frontend → 用户 : 展示在「我的MCP」，可直接使用
🔥 热数据来源（可调用的MCP链接）
热源1 网关导入的MCP
管理员导入网关MCP时 同时写入冷+热数据
热数据 = 网关的MCP SSE/HTTP链接
用户订阅后直接使用，不需要AgentRun
endpoint: https://gateway.xx/mcp/server-name
热源2a 用户直接导入MCP服务
用户直接填入已有的SSE/HTTP MCP地址
不需要AgentRun，直接作为热数据
发布后对其他用户是冷数据，订阅后变热
endpoint: https://user-mcp.xx/sse
热源2b 用户上传元数据 → AgentRun托管
用户上传MCP元数据 → 自动调AgentRun
AgentRun生成沙箱MCP链接 → 保存为热数据
发布后对其他用户是冷数据，订阅时再次AgentRun
endpoint: https://agentrun.xx/sandbox/mcp/abc123
热源3 第三方市场MCP → AgentRun托管
用户订阅第三方市场的MCP时
调AgentRun托管 → 生成沙箱MCP链接
保存为该用户的热数据
endpoint: https://agentrun.xx/sandbox/mcp/def456

📱 前端页面视图
MCP广场（冷数据展示）
• 展示所有公开的MCP元数据卡片
• 来源标签：管理员添加 网关导入 第三方市场 用户发布
• 卡片信息：名称、描述、tools数量、协议类型
• 操作按钮：「订阅」→ 触发冷→热转换流程
• 搜索、分类筛选、分页
我的MCP（热数据展示）
• 展示用户已订阅的MCP，都有可用的endpoint
• 显示MCP连接地址（SSE / HTTP）
• 可直接被Chat调用
• 操作按钮：「复制链接」「取消订阅」「发布到市场」
• 来源标签：网关 AgentRun 自定义
• 「+ 添加MCP」入口：上传元数据 或 直接填入SSE/HTTP地址
📊 数据模型
❄️ mcp_cold（冷数据/元数据表）
id BIGINT PK
name VARCHAR(64) — MCP名称
description VARCHAR(512) — 描述
icon JSON — 图标
source_type ENUM — git/npm/docker/config
source_url VARCHAR(512) — 源地址
env_vars JSON — 环境变量
tools_config TEXT — tools YAML
origin ENUM — admin/gateway/user/third_party
visibility ENUM — public/private
publish_status ENUM — draft/pending_review/published
gateway_id VARCHAR(64) — 网关来源ID(可空)
third_party_source VARCHAR(128) — 第三方市场标识(可空)
created_by VARCHAR(64) — 创建者
create_at DATETIME
🔥 mcp_hot（热数据/可调用MCP表）
id BIGINT PK
mcp_cold_id BIGINT FK — 关联冷数据
user_id VARCHAR(64) — 所属用户(可空=全局)
endpoint_type ENUM — sse/http/stdio
mcp_endpoint VARCHAR(512) — MCP访问地址
hot_source ENUM — gateway/agentrun/user_direct
sandbox_instance_id VARCHAR(128) — AgentRun实例ID(可空)
gateway_id VARCHAR(64) — 网关ID(可空)
status ENUM — running/stopped/failed
create_at DATETIME
📋 mcp_subscription（订阅关系表）
id BIGINT PK
user_id VARCHAR(64) — 订阅用户
mcp_cold_id BIGINT FK — 关联冷数据
mcp_hot_id BIGINT FK — 关联热数据
status ENUM — active/cancelled
create_at DATETIME
